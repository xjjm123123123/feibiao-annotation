# 飞标-V1.4.12-协同批注版

飞标-V1.4.12 从 v1.4.11 继续维护，首次点击先显示轻量启动状态并优先打开顶层侧栏，iframe 标注能力随后后台就绪；协同、登录与完整标注能力保持不变。

包含：

- DOM 评论、截图批注与页面定位。
- 评论中的试改：文案、字号、字重、颜色、背景、透明度、间距、圆角与对齐可实时预览，并支持当前会话撤销/重做；保存后可在阅读模式通过 `B/A` 回看单条批注的 Before / After，删除试改批注会同步恢复该元素的原样式。
- DOM 评估、DOM 试改、截图三类标注；同一位置可保留多条标注。
- 标注的二次编辑、轻量归档、截图预览和 JSON 导入/导出。
- 飞书登录与 Team 选择：只展示机器人已加入且当前用户属于其中的群聊。
- 群聊选择使用飞标自有浮层列表，展示群聊头像与选中态，不依赖 Chrome 或操作系统的下拉样式。
- 一个 Team 自动创建并复用一份 Base，不同网页按 Page Key 自动归类。
- 批注支持回复、解决和恢复；初始批注为一级，全部回复统一缩进为二级。
- 回复有两个入口：悬浮批注时点击回复箭头，或直接点击批注卡片，在卡片底部展开输入框；回复、编辑和删除图标保持一致的视觉权重，DOM 使用淡紫色，截图使用淡橙色。
- 批注卡片不再显示重复的气泡/相机类型图标；试改批注右上角依次显示 `B/A` 与解决/恢复入口。
- 顶部工具栏不再显示“试改前后”，单条试改统一通过对应批注右上角的 `B/A` 图标切换。
- “解决”使用卡片右上角的圆圈对钩入口，待处理与已解决使用不同状态色。
- 已解决批注使用回转箭头恢复为待处理，不与“标记为已解决”的圆圈对钩混用。
- DOM 与截图批注可点击 `@` 浏览成员；回复框移除独立 `@` 图标，直接键入 `@姓名` 实时筛选。所有场景选中后都以飞书风格 mention 显示并发送真实 @。
- `@` 候选、初始批注作者及回复作者统一显示真实飞书头像；旧回复按作者 Open ID 自动补齐头像。
- 批注库链接默认直达“飞标协同批注”表；包括飞书预生成 10 条全空占位记录在内的新旧默认空表都会被安全清理。
- “发起人”使用飞书人员字段，历史文本列会依据已保存的 Open ID 自动迁移，姓名可直接打开人员信息。
- 飞标机器人以互动卡片单聊提醒：新批注包含预览配图、内容与标注位置，回复明确区分原批注和本次回复；发起人使用可点击 mention，定位按钮可一键打开原网页并自动切换 Team、同步和聚焦对应批注。
- 登录状态有效期为 30 天；24 小时内复用本地有效会话，不在每次操作前重复联网校验，达到校验窗口后成功校验会自动续期 30 天。
- 单一刷新入口同时更新可用群聊与当前页批注。
- 支持将当前页面以带网站内容预览的飞书卡片分享到已选群聊；打开链接后自动展开飞标并同步该页全部批注。
- 分享弹窗显示目标群聊、网站截图、备注、取消和分享；备注支持键入 `@姓名`。普通分享不提醒任何人，仅主动 @ 的成员会收到提醒。
- 取消、Esc 或点击遮罩不会产生群消息。
- Team Base 全群默认可编辑，创建者和群主拥有管理权限。
- 最近使用的 Team 保存在 Chrome 本地，跨网页默认恢复。
- 每个人使用自己的飞书账号，并由群成员身份控制访问。
- 单栏 Agent 交付窗口：默认整理当前页面批注，回复过程不自动写入；支持精简/完整 Markdown、直接编辑、复制及附件打包。
- 飞书云文档保持一键同步，不增加手动选择；仅同步待解决批注，并在每条批注下附带完整回复内容、回复人和时间。

安装：

1. 打开 Chrome 扩展管理页：`chrome://extensions/`
2. 开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 解压 `飞标-V1.4.12-协同批注版.zip`，将内容覆盖到 Chrome 当前加载的固定扩展目录。

Chrome 会识别为独立插件：`飞标-H5页面标注助手`，当前版本展示名为 `V1.4.12-协同批注版`。

安装后网页默认保持干净，不会自动显示飞标界面。需要使用时，点击 Chrome 工具栏中的飞标图标，即可唤起主功能条和标注面板。

为减少浏览器安装和网页加载负担，v1.4.12 不再向所有网页及 iframe 自动注入完整脚本与样式；点击飞标后才向当前页面按需注入，并先显示面板，再异步刷新 Team 数据。分享深链打开目标网页时仍会自动注入并展开面板。

本版本以飞标协同批注 PRD 和 v1.4 需求为产品与验收依据。
